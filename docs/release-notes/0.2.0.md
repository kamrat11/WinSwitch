**Install:** download **WinSwitch-0.2.0.dmg**, open it and drag WinSwitch to Applications, plus Notepad, Notepad++ and MS Paint if you want them. Start WinSwitch, then allow the permissions described in the [README](https://github.com/kamrat11/WinSwitch#permissions).

Signed with a Developer ID and notarized by Apple. Requires macOS 15 or later. Runs on Apple silicon and Intel Macs.

## What's new

**New apps**
- **Notepad:** works like the Windows 11 Notepad, with tabs, Find and Replace, Go to, Time/Date (F5), encodings and line endings, and unsaved tabs kept between starts.
- **Notepad++:** built on Scintilla, the same editing component as Notepad++. It has syntax highlighting for 60+ languages, folding, Find in Files, Mark, bookmarks, multi-caret and column editing, Function List, Document Map, macros and Notepad++'s menus.
- **MS Paint:** works like the Windows 11 Paint, with brushes, shapes, text, fill, selections, rotate, flip, resize and skew, zoom with gridlines, and PNG, JPEG, BMP, GIF, TIFF and HEIC files.
- All three use a Windows-style **Save As** dialog whose File name box takes a full path. `notepad`, `notepad++` and `mspaint` in the Run box (Win+R) open them.

**WinSwitch**
- **Task Manager (Ctrl+Shift+Esc):** Processes, Performance graphs, Startup apps, Users, Details and Services.
- **File Explorer:**
  - **This PC** shows every disk with a capacity bar.
  - **Properties** (Alt+Enter) shows folder sizes and a disk's used and free space.
  - **Share** opens AirDrop, Mail and the other share options.
  - **Ctrl+click** adds or removes one item from the selection.
  - Large copies run in the background with a progress window.
  - Files copied in Remote Desktop can be pasted.
  - Full Disk Access is offered so Explorer can open every folder.
- **Dock previews:** stay open when you click the Dock icon, and while you move up to them across other icons.
- **PrtSc** copies the screen you're working on (the one under the mouse), and **Alt+PrtSc** the active window, including web pages in Chrome that used to come out blank.
- **Drag from File Explorer** into other apps (CapCut, video and photo editors) works like a drag from Finder.
- **Alt+F4:** closes WinSwitch's own windows instead of quitting it.
