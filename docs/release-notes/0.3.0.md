**Install:** download **WinSwitch-0.3.0.dmg**, open it and drag WinSwitch to Applications, plus Notepad, Notepad++ and MS Paint if you want them. Start WinSwitch, then allow the permissions described in the [README](https://github.com/kamrat11/WinSwitch#permissions).

Signed with a Developer ID and notarized by Apple. Requires macOS 15 or later. Runs on Apple silicon and Intel Macs.

## What's new

- **Window buttons in the Dock previews:** with the mouse on a preview, the Mac's red, yellow and green buttons appear in its corner. Red closes that window, yellow minimizes it, and green makes it full screen. On a minimized window, yellow and green restore it. Closing keeps the previews open and slides the next one under the mouse, so several windows can be closed one after the other.
- **Which window is asking for attention:** when a Dock icon jumps or shows a badge, macOS does not say which window it is about. Now the Alt+Tab tiles and the Dock previews do:
  - The app's Dock badge (the red number) is repeated on the app icon of each of its windows.
  - A Terminal window that rang the bell gets an orange frame and an orange bell, so with many Terminal windows open you can see which one is waiting for you. The mark goes away once you look at that window. The first time, macOS asks to let WinSwitch control Terminal; that is how it finds the window that rang.
