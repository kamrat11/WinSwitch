**Install:** download **WinSwitch-0.2.1.dmg**, open it and drag WinSwitch to Applications, plus Notepad, Notepad++ and MS Paint if you want them. Start WinSwitch, then allow the permissions described in the [README](https://github.com/kamrat11/WinSwitch#permissions).

Signed with a Developer ID and notarized by Apple. Requires macOS 15 or later. Runs on Apple silicon and Intel Macs.

## Fixes

- **Copying from Remote Desktop into File Explorer:** files pasted or dragged from a Remote Desktop session (Windows App) could arrive with parts of them missing, because Explorer copied them while Windows App was still receiving them. Explorer now waits until each file has fully arrived and checks the copy against the original.
- **Alt+Shift+Tab** right after an Alt+Tab goes back to the window you just left. The window you switch away from is also remembered correctly, including one from an app that has just opened.
- **File Explorer in the Dock:** while Explorer is open, the Dock shows a folder icon for it instead of WinSwitch's own icon.
